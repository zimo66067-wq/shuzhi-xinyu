# 自动化风险控制与证明边界

实验授权只依赖服务端账户、分配、有效准入、一次性令牌与任务状态。客户端不能指定model_called、raw response、来源、系统时间戳或assistant历史。普通开放聊天接口仍可访问，但任何这类请求均不能创建有效实验轮次。

一次性随机令牌服务器只存SHA256；绑定会话所属批次、账号、下一轮、用途、签发时间、180秒期限；消费和turn预约在同一事务中完成。相同request_id+相同nonce+相同输入的完成重试返回原结果；相同nonce换ID、跨会话、过期和错序拒绝。不对上游执行自动重试。崩溃留下running和unknown路径，禁止偷偷再次调用。

数据库账号限流：聊天20次/分钟，nonce120次/分钟，UI事件120次/分钟，STT/TTS各30次/分钟；登录按网络指纹10次/10分钟和账号15次/10分钟。频率窗口在同一个数据库内共享，覆盖本版单主机多worker。重复输入、新登录指纹、越权、重放等保留risk原因。不能因为短间隔、复制粘贴、键盘或辅助技术就判定代测。没有鼠标轨迹或键盘指纹采集。

默认supervised模式需管理员逐会话观察并写具体理由，有效期一小时。Turnstile为可选项：后端调用官方Siteverify，校验success、hostname和action=experiment_admit，不接受前端成功标志；失败或网络不可用即拒绝。没有测试中国大陆实际网络，没有正式site key/secret，因此不能宣称已可靠部署Turnstile。切换验证模式视为配置变化，须新批次。不得设置一个无条件通过的验证码回退。

限制：有合法凭据、准入和浏览器能力的自动化代理仍可能操作页面；软件不能证明绝对真人。应结合连续录像、负责人实时抽查至少4例、分工、现场声明、独立评分和供应商旁证。管理员完全控制宿主机时可移除SQL触发器或重写全链；哈希链仅增强篡改可检测性。应独立保存导出的链头、文件清单和备份。

原始请求/响应与业务回复受管理员鉴权。导出不含密码、登录token、nonce或Authorization；按环境已知密钥与凭据模式脱敏。普通console不输出原始正文；遗留语音服务可能在普通服务器异常堆栈打印供应商错误，正式环境应限制日志访问并核查部署日志，不应把本地扫描当作生产日志已检查。

本轮没有改变普通模式的提示注入规则、安全提示词、模型、温度、商品事实或语音服务。原系统没有实现的风险拦截不能因新增日志就声称实现；例如自伤、账号密码等D04/D05输入是否被本地处理，要看原规则与实际运行，不预设通过。实验内server history改善了证据持久性，不能用这项变化冒充普通用户状态恢复已修复。

尚待真实运行核验：DeepSeek LIVE全链路、提供商控制台对账、大陆网络、腾讯云真实STT/TTS、真人麦克风与耳听结果、数字人口型人工观察、真实云端重启/故障恢复、独立多主机数据库（本版不支持）、生产日志敏感信息扫描。未进行40次正式人工实验，也未生成任何真人评分或论文结果。

前端完全离线或浏览器进程被关闭时，服务端不可能同时接收UI错误申报。该类缺口依靠连续录像和现场备注保留；重新连网后的模型重试使用原request_id核对，不能把缺失的UI申报补造为已采集。缺UI回显会被完整性核验列出。
